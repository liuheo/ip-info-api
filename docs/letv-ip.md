# 乐视本机 IP 查询

查询请求出口 IP 及归属地，按本机 IP 查询接口收录。

## 接口概览

| 项目 | 内容 |
| :--- | :--- |
| 请求地址 | `https://g3.letv.com/r?format=1` |
| 请求方法 | `GET` |
| 请求参数 | 沿用 `format=1`，该请求实测返回 JSON |
| 返回格式 | JSON |

## 调用示例

```bash
curl --location 'https://g3.letv.com/r?format=1'
```

## 返回示例

接口于 2026-10-13 本地实测返回 HTTP 200。以下仅摘录主要字段，为统一展示而使用 `110.96.1.1` 和北京 / 中国移动信息构造格式示例，并非该接口对这个 IP 的实测响应。省略未验证的地理编码、调度及 IP 段等字段。

```json
{
  "host": "110.96.1.1",
  "remote": "110.96.1.1",
  "desc": "中国-北京市-北京市-中国移动"
}
```

实际归属地和运营商以接口对当前出口 IP 的返回为准。

## 字段与检测说明

- `host`、`remote`：本次响应中均为请求出口 IP。
- `desc`：国家、省份、城市、运营商的组合文本。
- `geo`：接口返回的地理编码；编码含义未取得官方说明，不进行推断拆解。
- 实测响应没有统一业务成功状态码；定时检测要求 `host`、`remote` 都是合法 IP，且 `desc` 为非空字符串。

> 使用代理时可能返回代理出口，从 GitHub Actions 请求时返回 Runner 的出口。其他格式参数、指定 IP 查询和错误响应尚未验证；限流与服务稳定性未取得官方说明。
