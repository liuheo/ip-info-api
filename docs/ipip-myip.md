# IPIP 本机 IP 查询

查询请求出口 IP，以数组形式返回地理信息，按本机 IP 查询接口收录。

## 接口概览

| 项目 | 内容 |
| :--- | :--- |
| 请求地址 | `https://myip.ipip.net/json` |
| 请求方法 | `GET` |
| 请求参数 | 本次调用不需要参数 |
| 返回格式 | JSON |

## 调用示例

```bash
curl --location 'https://myip.ipip.net/json'
```

## 返回示例

接口于 2026-10-13 本地实测返回 HTTP 200。以下保留字段结构，为统一展示而使用 `110.96.1.1` 和北京 / 中国移动信息构造格式示例，并非该接口对这个 IP 的实测响应。

```json
{
  "ret": "ok",
  "data": {
    "ip": "110.96.1.1",
    "location": ["中国", "北京", "北京", "", "中国移动"]
  }
}
```

## 字段与检测说明

- `ret`：实测成功值为字符串 `"ok"`。
- `data.ip`：请求出口 IP。
- `data.location`：地理信息字符串数组。本次内容为国家、省份、城市、空字符串、运营商；第四项含义未验证，不假设其固定语义。
- 定时检测要求 `ret == "ok"`、`data.ip` 是合法 IP、`data.location` 是非空字符串数组且至少一项非空；允许部分位置为空。

> 使用代理时结果可能为代理出口，从 GitHub Actions 请求时返回 Runner 的出口。不要固定本机 IP 或国内地理信息作为检测条件。限流、错误码及数组结构的长期稳定性未取得官方说明。
